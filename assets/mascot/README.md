# Pico — Sico 吉祥物

啄木鸟 Pico：一啄 = 一条诊断，短、准、稳定、低 token；站在一块六边形 Component 积木上。

## 文件

- `pico.svg`：扁平风格矢量图标（64×64 viewBox，透明背景）
- `pico.ansi.txt`：终端画（24-bit 真彩色半块字符，48 列 × 24 行），用 `cat` 直接显示
- `pico.ascii.txt`：单色 ASCII 版本，无颜色环境使用
