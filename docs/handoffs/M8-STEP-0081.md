## 1. 一句话状态

STEP-0080 已完成：`sico build --profile script-v0` 产出确定性 Program Component，versioned `sico:script/adapter@0.1.0`（SHA-256 `185ebf1d393cb2b93c1d023f89d19d36c323c64f858a2fef1092f6a0283502c7`，2,198 字节）把 Program 组合成 WASI 0.2.12 command（wasmtime CLI 实跑 echo 双通道 exit 0 / reject stderr exit 1），严格 manifest v1 记录精确 world/semantics/WIT/adapter identity 并把 import 闭包映射到 `script.args`/`script.stdio`。下一项 STEP-0081 负责结构化 in-process `sico-runner`（typed Wasmtime fault mapping、WASI context、limits、无 ambient env/fs/network、恶意 guest 后 host 存活）。

## 2. 已冻结实现边界

- Program 边界：`sico:script/program@0.1.0`，源码 `main` → IR/边界 `run`；四个 Script 声明显式书写并按冻结 ABI 形状校验；source `snake_case`/`CamelCase` ↔ WIT `kebab-case`。
- Adapter 组合：`crates/sico-app-cli/src/compose.rs`（`script_adapter_component`/`compose_script_command`）；WASI 版本 pin `0.2.12`；stdin EOF = `stream-error::closed`；WASI 0.2 exit 只有 0/1——**精确 0..=119 guest code 与 120..=127 工具映射是 STEP-0081/0082 direct-runner 契约，不是 adapter 输出**。
- manifest v1（`sico.sapp.manifest.v1`，`sico-package`）：严格 `deny_unknown_fields`，`script` 块记录 profile/world/entry/semantics(`sico.ir.v0`)/wit(`sico:script@0.1.0`+SHA-256)/adapter(id+SHA-256)；`build_script_v1`；v0 不得带 script 块；closure 映射在 `capabilities_for_imports`（types-only 实例免 capability；未知 import/版本 fail closed）。
- Component Model 编码教训：接口以 instance import；资源不能声明在 instance type 里（用 SubResource export 引入）；variant/record/enum 必须命名（Eq export）且 func 引用 export 索引；方法导出名 `[method]type.name`；plain-name SubResource type import 运行时要求 linker 资源实现。
- Wasmtime hostcall fuel 按元素计费，runner 必须按调用预算（128 Mi 默认不够 8 MiB 通道）。
- `sico_runtime::canonical`（独立 lift/lower helper）已就绪但尚无消费者——STEP-0081 runner 是它的天然用户。

## 3. STEP-0081 执行顺序

1. 冻结 runner 故障分类：typed Wasmtime fault mapping（trap/fuel/timeout/memory/launch）→ 结构化输出（不是 stderr 文本解析）。
2. in-process 调用 Program export（direct fallback 已是测过路径）或运行 composed command；WASI context 明确无 env/cwd、无 ambient fs/network。
3. 接入 HostLimits/manifest limits 与 fuel/timeout/memory gate；恶意 guest（trap、死循环、内存炸弹、畸形结果）后 host 存活并可继续下一次调用。
4. 精确 exit 语义：guest 0..=119 原样、ScriptError → 122、cancel 123、timeout 124、resource-limit/trap → 125、launch → 126、missing/incompatible → 127。
5. 证据通过后才进入 STEP-0082 unified `sico run`/`eval`/caches。
