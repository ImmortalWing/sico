## 1. 一句话状态

STEP-0090 已完成 persistent runner/watch：Engine、八项 Component cache 与 prepared Linker 可复用，每次运行仍新建 Store/resource table/IO/cancellation state；`sico watch` 只发布成功编译并合并快速写入。下一项 STEP-0091 是 bounded REPL session model。

## 2. 已冻结事实

- watch authority 在进程启动时固定，源码不能扩大 fs/network grants。
- 每次执行必须新建 Store；禁止复用 guest globals、resource handle、IO worker、取消状态或 HTTP terminal state。
- source ≤8 MiB、Component ≤64 MiB、compiled cache ≤8、poll 5–1000 ms、stable debounce 100 ms。
- invalid compile 保留上一健康 generation 但不重跑；typed error/trap 不终止 persistent runner。
- watch v0 拒绝 streaming stdin，避免把一次性 OS stream 冒充可重放输入。
