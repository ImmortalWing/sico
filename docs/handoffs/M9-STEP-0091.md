## 一句话状态

STEP-0091 已完成 bounded expression REPL：deterministic cell IDs、failed-cell rollback、history/export replay、reset 与明确资源上限均闭环。下一项 STEP-0092 必须独立裁决 top-level script syntax。

## 冻结边界

- RFC-0032 v0 只接受现有 compile-time `Int` expression，不暗示 top-level statement 已接受。
- cell ≤4 KiB、count ≤256、history ≤16 KiB、export path ≤4 KiB。
- `:history`/`:export` 前全量 replay；`:reset` 清空 source/result/ordinal。
- export 只做用户显式路径的 `create_new`，不覆盖文件。
- REPL 无 Store、resource、network、process 或 ambient filesystem authority。
