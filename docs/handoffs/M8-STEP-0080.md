## 1. 一句话状态

STEP-0079 已完成 WIT 驱动的 aggregate Canonical ABI：bounded arena + checked arithmetic、Text/Bytes/list\<Text\>/Script records/Result 的 lift/lower、确定性 `cabi_post_run` 清理；10,000 个 seeded Wasmtime 46.0.1 roundtrip、512 × 1 MiB + 8 × 4 MiB 单实例 cleanup oracle、1,024 参数/8 MiB 边界用例与 6 个恶意内存 fail-closed fixture 全部通过。下一项 STEP-0080 负责 compiler Script profile、adapter composition 与 manifest v1 集成。

## 2. 已冻结实现边界

- Layout 表：`docs/development/script-canonical-abi-layout-v0.md`，由 `crates/sico-codegen-wasm/src/canonical.rs` 从内嵌 `wit/script-profile-v0/world.wit` 派生；手工偏移量一律视为缺陷。
- 生成的 Program core module 导出 `memory`（固定 1,024 页）、`run`、`cabi_realloc`、`cabi_post_run`；Component 只 import types-only 实例 `sico:script/types@0.1.0` 并 lift `run`（utf8/memory/realloc/post-return）。
- 每实例一个 bounded arena：静态字面量在 data segment，arena base 紧随其后，ceiling 64 MiB；`alloc`/`realloc` checked arithmetic，越界 trap；`cabi_post_run` 幂等重置 bump pointer。
- result payload 字节在 lower 时复制进 arena，不与调用方输入缓冲区共享存储。
- IR 新增 `Type::Bytes`、`Type::List(Box<Type>)` 与 `Operation::ConstBytes`；源码层 `Bytes`/`List` 名称映射刻意未启用（`newtype Bytes` 等用户类型优先），STEP-0080 需要时按 shadowing 规则接入。
- 内部 record/variant 仍是 flat locals，不是公开 ABI；aggregate helper 参数、aggregate call transport、list 元素访问、非边界 aggregate 仍 typed-refuse（list 元素访问留给 STEP-0083）。
- 动态任意精度 `Int` 仍未实现，不能改为固定 i64。
- Wasmtime hostcall fuel 按元素计费（lower `len*size_of::<T>()`、lift `len*size_of::<Val>()`），runner/harness 必须按调用重置或放大预算（默认值 128 Mi）。

## 3. STEP-0080 执行顺序

1. `sico build --profile script-v0`：源码 `main(input: ScriptInput) returns Result[ScriptOutput, ScriptError]` 经 semantics → IR → `compile_script_program`。
2. 接入 STEP-0076 选定的 versioned Adapter composition（direct Program invocation 作为已测 fallback），记录 adapter 与 WIT 精确 digest。
3. 严格 manifest v1：entry kind/world、language semantics、Script WIT、adapter 与最终 Component identity；未知值 fail closed。
4. 验证 composed command imports 与 package closure；确定性 artifact 快照。
5. 精确证据通过后才开始 STEP-0081 in-process runner。

## 6. 不得误报

- STEP-0079 的 aggregate ABI 只是边界传输：guest 内部仍是 flat locals，没有 list 元素访问、没有 aggregate call transport、没有源码层 Script 语法。
- 参数 list\<string\> 的元素内容经独立 host helper 与 STEP-0076 硬编码 guest 验证；编译器生成的 guest 目前只能回传 count/transport，元素内容回传待 STEP-0083。
- `sico_runtime::canonical` 是独立校验实现，尚未被任何 in-process runner 消费（STEP-0081）。
- STEP-0080 不包含 runner、CLI/cache、stdlib 或 M9 streaming/async。
- M6 Android、M7 public production 与真实第三方/live-model 外部 gate 没有变化。
