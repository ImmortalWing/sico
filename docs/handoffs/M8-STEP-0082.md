## 1. 一句话状态

STEP-0081 已完成 in-process `sico-runner`（`runner/sico-runner`，workspace 外产品 crate，MSVC 构建）：direct Program export 调用、每调用一个新 Store、无任何 WASI 上下文、RFC-0029 全部 exit class 走 typed 路径（0..=119 精确、122 domain、123 cancel、124 timeout、125 fuel/memory/trap、126 launch、127 incompatible、121 CLI），恶意 guest（trap/fuel/memory/畸形结果）后 host 存活。下一项 STEP-0082 负责 unified `sico run`/`eval` 与安全 caches。

## 2. 已冻结实现边界

- runner：`runner/sico-runner`（lib `Runner::run_program` + CLI `sico-runner [--json] PROGRAM [-- ARGS...]`）；`RunOutcome` typed 分类不读 engine 错误文本（fuel 读回 0、epoch marker error、自有 ResourceLimiter 记录拒绝）。
- timeout 用 epoch deadline（5 ms tick，非确定性界）；fuel 是确定性非终止 gate；hostcall fuel 按调用按输入大小预算。
- guest exit 超出 0..=119 拒绝（Trap/125），绝不截断；stdout purity：只有 Output 写 stdout，诊断一律 JSON（`sico.runner.outcome.v0`）上 stderr。
- runner 只跑 Program Component；composed WASI command 由 `sico-app compose` 产出，exit 只有 0/1；runner 对 composed artifact 拒绝执行。
- 构建链：`sico build --profile script-v0`（sico-cli）、`sico-app compose`、`sico-app pack --script`（manifest v1，`sico.sapp.manifest.v1`）。
- runner crate 只能 MSVC 链接（vcvars64.bat，stdout 不可重定向；Enter-VsDevShell 本机失败）；workspace 门禁保持 GNU 1.97.0。
- cache 契约（RFC-0029 §cache identity）：domain `SICO-SCRIPT-SOURCE-CACHE-V0\0`，十个固定顺序字段（compiler digest/build ID/semantics ID/script WIT version/adapter digest/source bytes/app id+version/profile `script-v0`/manifest schema/codegen options），u64 LE 长度前缀；命中必须结构性+加密+capability 重验。

## 3. STEP-0082 执行顺序

1. `sico run FILE.sico -- ARGS`：编译 → （可选 compose/pack）→ runner 执行；`sico run -` 读源码 stdin 且 guest stdin 为空（单流不二义）。
2. `sico eval "EXPR"`：内存合成 Candidate A（不新增语法）。
3. source cache：按冻结 cache key 存 compiled Program Component；命中重验后才执行；损坏/过期 fail closed；create-new 临时文件 + 原子提交；并发写不覆盖歧义/损坏项。
4. machine cache：Wasmtime 编译产物按 Component digest + engine/target/config keying（可选，做不到就明确记录放弃并给证据）。
5. JSON 诊断契约、stdout purity、超时/fuel 默认上限、cache 并发/损坏负例全部通过后进 STEP-0083 stdlib。
