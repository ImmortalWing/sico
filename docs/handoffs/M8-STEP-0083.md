## 1. 一句话状态

STEP-0082 已完成：`sico run FILE.sico -- ARGS` / `sico run -` / `sico eval "EXPR"` 端到端可用，编译产物按冻结 `SICO-SCRIPT-SOURCE-CACHE-V0` identity 缓存（复用/新键/损坏均验证），经 `sico-runner` 跨进程执行，exit/stdout/诊断契约完整。下一项 STEP-0083 是最小可用 script 标准库（text/bytes/list/JSON/scoped-fs）与四个 pilots。

## 2. 已冻结实现边界

- `sico run` 在 `crates/sico-cli/src/run.rs`；cache 在 `crates/sico-cli/src/cache.rs`（domain `SICO-SCRIPT-SOURCE-CACHE-V0\0`，10 个固定顺序字段，u64 LE 长度前缀）。
- runner 委托：`SICO_RUNNER`（权威，坏路径 fail closed 127）→ sibling → PATH；runner 只跑 Program Component；composed WASI command 由 `sico-app compose` 产出。
- `sico eval` 只接受编译期常量 Int 表达式（其余 120）；Candidate A 以验证过的 IR 内存合成，没有新语法。
- engine machine-code cache 已如实记为 deferred（`wasmtime-internal-cache` 不在本机离线 cargo 缓存）。
- adapter digest：`sico_package::compose::script_adapter_component()`；compose 已迁移到 `crates/sico-package/src/compose.rs`（`sico-app-cli` re-export）。
- Script 源码仍需显式书写四个声明（ScriptInput/ScriptOutput/ScriptError/ScriptErrorCode）；`Bytes`/`List[Text]` 由 profile 提供且用户类型 shadowing 优先；`error(...)` 已可用。
- IR/后端缺口（STEP-0083 需要）：`Type::List` 只有 List\[Text\]；list 元素访问（index/length/append）没有 IR op；Text→Bytes 转换没有 IR op；scoped fs 需要 capability/effect 通道（现在 effect 一律拒绝）。

## 3. STEP-0083 执行顺序

1. IR/后端补 list 元素访问（checked loads，对齐 STEP-0079 的 checked arithmetic）与 Text/Bytes 互转（Text UTF-8 验证已在边界保证）。
2. `sico.text`/`sico.bytes`/`sico.list` 最小原语（length/concat/trim/contains/prefix/split-lines/replace；bytes length/slice/concat/UTF-8；list length/checked get/append；map/filter/fold 需要 closures 或明确推迟）。
3. `sico.json` bounded parse/stringify（文档化数字精度契约）与 `sico.fs` scoped read/write/exists/list（Host-granted roots，capability 通道）。
4. 四个 pilots：args echo、word count、JSON filter、scoped file transform——不经 compiler/Runtime 修改即可运行。
5. 证据通过后进 STEP-0084 M8 审计。

## 6. 不得误报

- eval 只覆盖编译期常量 Int；engine machine-code cache 是 deferred 不是完成。
- composed 路径 exit 只有 0/1；runner timeout 是 epoch（非确定性界）。
- scoped fs/environment 的 capability 通道尚未存在——不得在本步偷偷开 ambient 权限。
- M6 Android、M7 public production 与真实第三方/live-model 外部 gate 没有变化。
