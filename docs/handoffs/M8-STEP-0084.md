## 2. 已冻结实现边界

- intrinsic 三层登记：`crates/sico-ir/src/lib.rs`（`intrinsic_signature`）、`crates/sico-semantics/src/lib.rs`（`infer_stdlib_call`）、`crates/sico-codegen-wasm/src/lib.rs`（`emit_intrinsic`）。未登记名字一律拒绝。
- helper Wasm 函数：`crates/sico-codegen-wasm/src/stdlib.rs`（12 个）、`src/json.rs`（ws/string/number/scan/find/quote，scan 递归 depth≤32）。`sico.json.get` 返回原始 token 文本（字符串带引号是设计行为，数字只扫描不求值）。
- helper 函数（非 `run`）参数/返回支持 aggregate（`flat_ir_types` 扁平化）；Result 值全宽布局（tag+ok+err，非活动侧补零）；`run` 边界按运行时 tag If/Else 降 payload（`emit_script_return`）。
- `case ok(x)`/`case error(x)` 降成 `Project(base, "ok"|"error")`；IR 值块作用域 → match subject 必须是函数参数（非参数 subject 仍 typed 拒绝）。arm 必须是单 `return`，函数内 match 必须是首个语句 → 用 helper 函数扁平化控制流（pilots 即此结构）。
- fs：WIT 双接口（`wit/script-profile-v0/world.wit`）；codegen 把用到的 `sico.fs.*` 变成 component import，经 per-program transport 模块（独占 64 MiB memory + 单一 bump allocator，`heap_base` 在静态数据之上）；无 fs 的程序产物字节不变（快照未动）。
- runner（`runner/sico-runner`）：fs 实例总是链接；`--fs-read-root`/`--fs-write-root` 可重复，启动时 canonicalize；guest 路径必须相对、≤4 KiB、无 `..`/盘符/冒号/反斜杠，canonical containment 校验（symlink 逃逸拒绝）；文件 ≤8 MiB；`sico run` 透传同名 flags。
- package closure：`sico:script/fs-read@*`→`storage.read`，`fs-write@*`→`storage.write`（`capabilities_for_imports` + `is_supported_capability`）。
- runner ResourceLimiter：instances 上限 2（program core + fs transport）。
- 工具链：workspace 一律 `RUSTUP_TOOLCHAIN=1.97.0-x86_64-pc-windows-gnu`（offline/locked）；runner/MSVC 用 `stable-x86_64-pc-windows-msvc` 且必须先 `call vcvars64.bat`（`target\build-runner.bat` / `target\test-runner.bat` 可复制此模式；cmd 调用必须 `cmd.exe //c`，vcvars stdout 不可重定向）。
