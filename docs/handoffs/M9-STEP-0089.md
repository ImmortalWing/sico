## 1. 一句话状态

STEP-0087/0088 已完成质量修复：间接 Task 逃逸现由类型检查拒绝，blocked read/pump/write 均以控制退出码 123 在 120–134ms 内取消，256 MiB passthrough 无回归。STEP-0089 已有 RFC-0031、WIT 和 codegen 草案，但 runner provider 未链接、`NetGrants` 保持 inert，当前默认无网络且不得宣称 HTTP 可用。

## 2. 已冻结事实（设计约束）

- M9 计划 §7:HTTP 是 versioned Component/Host provider，不是编译器 intrinsic；权限决策命名精确端点或可审计模式；默认无网络；`--allow-net api.example.com:443` 不授权其他 host/port/本地地址/重定向/监听。
- 契约已起草为 RFC-0031；完成实现前仍须复核 redirect、DNS、代理/TLS 明确延期、body/header 上限、凭证与日志脱敏边界。
- 能力通道先例：fs（`sico:script/fs-read/fs-write@0.1.0`,Host-granted roots）与 streams（资源句柄 + transport module）是现成模板；HTTP 建议走 `sico:script/http@0.1.0` 接口 + `network.connect` 能力名（`capabilities_for_imports` 已有该名）。
- 离线约束：本机 cargo 无 HTTP client crate——host 侧用 raw TcpStream + 手写最小 HTTP/1.1（仅 http://，或明确声明 https 需要额外依赖并如实推迟 TLS)。
- 取消模型:0088 的 worker/channel 可取消 IO 可复用（connect/read 阻塞同样可中断）。
- 工具链：workspace `1.97.0-x86_64-pc-windows-gnu`;runner/MSVC `target\build-runner.bat`(cmd 必须 `//c`);WSL Ubuntu 可做 Linux 证据（有网络）。

## 3. STEP-0089 执行顺序（建议）

1. RFC-0031:scoped HTTP 契约（端点精确匹配、无 redirect 或 1 跳同 host、body/header 上限、无凭证、错误分类、日志脱敏、无 listener)。
2. WIT 接口 `sico:script/http@0.1.0`（请求/响应 record + 状态/错误枚举）+ capability 映射 `network.connect`。
3. runner host：精确端点校验（host:port 全等匹配，防 DNS rebinding：解析后 IP 也需落在授权集合或如实只授权域名+系统解析）、body ≤8 MiB、header ≤64 KiB、超时、取消。
4. 本地回环证据：WSL/python http.server 或本机最小 server fixture;deny 用例（未授权 host、redirect 出界、超限）全 typed。
