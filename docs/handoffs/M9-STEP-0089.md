## 2. 已冻结事实（设计约束）

- HTTP 是 versioned Component/Host provider，不是编译器 intrinsic；默认无网络，`--allow-net HOST:PORT` 仅授权规范化后的精确端点。
- RFC-0031 v0 只接受 `http://`、GET/POST、ASCII DNS 或 canonical IPv4；不跟随 redirect，不支持 TLS、IPv6、IDNA、代理、凭证或 listener。
- Host 使用最小 raw HTTP/1.0/1.1 provider；URL 8 KiB、header 64 KiB、body 8 MiB、connect 2 秒、总计 5 秒，拒绝 chunked/ambiguous framing。
- WIT import 精确映射到 package capability `network.connect`；授权校验发生在 DNS/socket 之前。
- blocked connect/read/write 在 worker 中运行，runner 每 2 ms 检查取消/总超时；超时后该 Store 的 HTTP 通道终止，避免脚本累积遗留 worker。
- 工具链：workspace `1.97.0-x86_64-pc-windows-gnu`;runner/MSVC `target\build-runner.bat`(cmd 必须 `//c`);WSL Ubuntu 可做 Linux 证据（有网络）。
