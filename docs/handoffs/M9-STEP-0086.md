## 1. 一句话状态

STEP-0085 已完成：RFC-0030（proposed）冻结 M9 streaming channel——`sico:script/streams@0.1.0`（input-stream.read/output-stream.write+flush/stdin/stdout/stderr 构造器，stream-error=io/cancelled/closed/resource-limit），WIT 已并入 `wit/script-profile-v0/world.wit` 且解析通过。下一步 STEP-0086 是 resource Canonical ABI 与 stream codegen：owned/borrowed 句柄、exact drop、no use-after-close、bounded host calls 的真实实现。

## 2. 已冻结契约（实现不得偏离）

- read(max) 每调用 ≤64 KiB(host clamp)，空 ok = EOF(非错误)，错误即终态；write 全量或错误 ≤1 MiB/call,backpressure 阻塞不丢弃;flush 是唯一持久点,drop=output best-effort flush + close。
- 句柄 affine、每 run ≤64 个、随 Store 销毁；禁止跨 run 保留(persistent runner 只复用 Engine/Linker)。
- 映射到既有 `script.stdio` capability（同 buffered stdio 一样 auto-grant);buffered 与 streaming 同方向不可混用（边界 typed 拒绝）。
- intrinsic 表面方向（STEP-0086 注册）:`sico.stream.stdin`、`sico.stream.read`、`sico.stream.write`、`sico.stream.flush`、`sico.stream.close`。
- 取消:CancelToken 触发时 blocked read/write 返回 `stream-error.cancelled`,runner 仍出 `Cancelled` 123。

## 3. STEP-0086 执行顺序（沿用 fs 通道先例）

1. codegen:resource 句柄在 guest 侧是 Canonical ABI resource index(i32);fs 的 transport-module 模式可直接复用（streams 与 fs 可共存,import 计数叠加）。intrinsic 三层登记(IR/semantics/codegen)按 STEP-0083 模式。
2. resource 生命周期:guest drop → host `resource-drop`;use-after-close 必须 host 侧 typed `closed`（资源表,不靠 guest 自觉）。
3. runner:link streams 实例(stdin/stdout/stderr 构造器 + read/write/flush),handle 表 per-Store;cancel 时 blocked read/write 返回 cancelled。
4. 负例证据:use-after-close、超界 write、handle 跨 run 保留（如已有时）全部 fail closed;1/16 MiB passthrough 先行（256 MiB 归 STEP-0094）。
5. 证据报告 + step 记录 + validate-step-0086.ps1（含 bounded RSS 断言）。
