# Sico pilot programs

Pilots are release/workflow evidence, not language-design examples. They intentionally live outside `examples/`, whose files remain historical compiler and design baselines.

- [`third-party-component`](./third-party-component/README.md): clean-room-style public API consumer used by STEP-0069.

A repository-authored pilot can prove that documented public surfaces close locally. It cannot prove independent third-party usability, production service operation, legal identity, target-platform support or live-model performance; those require separately recorded external evidence.
