# Sico candidate A0 guide

- `newtype Name = Base` declares a nominal type.
- `record Name` and `enum Name` use indented members and close with `end`.
- Functions use `fn name(parameters) -> ReturnType`, an indented body, and `end`.
- Every function result is returned with `return`.
- Record and variant payload construction uses `Type(field: value)` or `Variant(value)`.
- Generic types use `Type<A, B>`.
- A match statement uses `match value`, arms written as `Pattern => return value`, and `end`.
- A successful Result is `ok(value)`; explicit error mapping is `.map_error(problem => match problem ... end)`.
- `capability`, `resource`, and `interface` declarations use indented members and close with `end`.
- Async functions add `async` before `fn`; `using value ... end` gives deterministic cleanup and `task group ... end` gives structured concurrency.
- Exported effectful functions add `export`, followed by indented `effects ...` and `capabilities ...` declarations before executable statements.
- Resource methods write `borrow self` for a borrow and `self` for a consuming receiver.
- Use the exact declaration and member order requested by the task.
