# AI evaluation run storage

真实模型原始输出默认不提交到 Git。本目录只保存策略，不保存运行数据。

受控实验存储中的每次运行至少保留：

- `prompt-packets.json`；
- `run.json` 原始输出记录；
- `score.json`；
- 三个文件的 SHA-256；
- 使用的 Sico 仓库提交；
- 供应商请求日志或批次 ID（不得包含凭据）；
- 保留期限和访问权限。

正式报告引用上述位置与哈希。经过脱敏、体积可控且确有长期回归价值的数据，必须通过新的审计步骤决定后才能加入仓库。
